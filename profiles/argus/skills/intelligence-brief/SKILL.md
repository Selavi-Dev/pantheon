# Collect new material intelligence

## Procedure
Search approved public sources; deduplicate by source/event; separate dates; rank relevance, confidence and urgency; report up to five developments and actions; no internal monitoring duplication.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
