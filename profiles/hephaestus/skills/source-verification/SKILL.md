# Verify and qualify source claims

## Procedure
Find original evidence; record URL or canonical record ID, publication/event/retrieval date, source type and confidence; check whether evidence directly supports claim; note conflicting evidence and missing data.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
