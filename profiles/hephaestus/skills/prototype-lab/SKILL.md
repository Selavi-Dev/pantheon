# Plan an isolated prototype

## Procedure
Confirm scope, approval and sandbox; choose minimal experiment; specify inputs, observable outcome and limits; return plan if sandbox unavailable; do not touch production or secrets.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
