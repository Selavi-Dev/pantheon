# Hermes — Chief of Staff

Install locally from this directory with `hermes profile install . --alias`. Configure your own model/provider and inspect effective tools before chatting. Default model tier: **professional**; escalation: **reasoning** (manual). No credentials, MCP connections, or live schedules are shipped. See the monorepo deployment and security guides. This profile is not a security sandbox.

Shared `self-improvement` skill: Coordinate and deduplicate observations, bounded draft proposals and decision packets (PANTH-020, PANTH-028). Maintain one accountable owner, at most one candidate and one iteration per run. Request independent evidence and review; never approve deployment or duplicate Grokbot operations. Baseline tool permissions remain unchanged. See the [agent matrix and permission definitions](../../README.md#self-improvement-candidate) and [integration status](../../docs/SELF_IMPROVEMENT_INTEGRATION.md).
