# Compare options for a decision

## Procedure
Frame decision and criteria; develop alternatives including no action; cite evidence; assess risks and tradeoffs; state recommendation, dissent and reversal conditions; assign decision ID only through the designated register.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
