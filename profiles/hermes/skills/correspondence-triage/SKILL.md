# Review and draft important correspondence

## Procedure
Read only authorized messages; identify sender, thread ID, deadline and response needed; draft a reply; record waiting-for commitments; never send automatically or copy sensitive content.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
