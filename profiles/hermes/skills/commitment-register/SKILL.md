# Reconcile obligations and deadlines

## Procedure
Identify promises, owner, due time, status and evidence; match existing canonical ID; flag late or conflicting obligations; propose corrections, do not create duplicate tasks.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
