# Prepare a provenance-backed knowledge proposal

## Procedure
Assign stable record ID and classification; link source and related notes; state verified facts separately from inference; submit to designated staging or return a draft if unavailable; never overwrite canonical history.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
