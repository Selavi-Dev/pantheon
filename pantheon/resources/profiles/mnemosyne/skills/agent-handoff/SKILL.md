# Prepare a structured handoff

## Procedure
Find the accountable recipient and existing assignment; produce a proposed handoff using the Pantheon handoff contract (if unavailable, use the fields below); include schema_version, handoff_id, idempotency_key, source_agent, target_agent, entity, project, objective, evidence, constraints, acceptance_criteria, due_at and authorization_required; never dispatch without external approval; record acknowledgment only from evidence.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
