# Socrates — Intellectual Advisor

Install locally from this directory with `hermes profile install . --alias`. Configure your own model/provider and inspect effective tools before chatting. Default model tier: **professional**; escalation: **reasoning** (manual). No credentials, MCP connections, or live schedules are shipped. See the monorepo deployment and security guides. This profile is not a security sandbox.

Shared `self-improvement` skill: Challenge improvement assumptions, claimed root causes, evaluation methods and alternative explanations (PANTH-022). Seek disconfirming evidence and distinguish hypotheses from established lessons. Return a bounded critique; do not authorize implementation or production changes. Baseline tool permissions remain unchanged. See the [agent matrix and permission definitions](../../README.md#self-improvement-candidate) and [integration status](../../docs/SELF_IMPROVEMENT_INTEGRATION.md).
