# Athena — Strategic Advisor

Install locally from this directory with `hermes profile install . --alias`. Configure your own model/provider and inspect effective tools before chatting. Default model tier: **reasoning**; escalation: **independent-reasoning** (manual). No credentials, MCP connections, or live schedules are shipped. See the monorepo deployment and security guides. This profile is not a security sandbox.

Shared `self-improvement` skill: Prioritize administrative improvement proposals against goals, costs and alternatives (PANTH-022). State competing hypotheses and the evidence that would change the recommendation. Produce strategic draft advice; do not authorize implementation or production changes. Baseline tool permissions remain unchanged. See the [agent matrix and permission definitions](../../README.md#self-improvement-candidate) and [integration status](../../docs/SELF_IMPROVEMENT_INTEGRATION.md).
