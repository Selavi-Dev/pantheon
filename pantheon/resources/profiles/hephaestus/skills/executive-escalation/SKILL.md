# Escalate material blockers or decisions

## Procedure
State severity, affected objective, evidence, decision required, owner and deadline; consolidate duplicate alerts; never infer approval; use private channel for private classification.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
