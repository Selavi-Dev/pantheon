# Evaluate release evidence

## Procedure
Inspect linked change IDs, tests, deployment evidence, approvals and rollback plan; distinguish local tests from deployed verification; report blockers; do not release or alter evidence.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
