# Evaluation protocol
Before testing, fix metric, direction, units, minimum practical improvement, sample size, benchmark inputs, model/tool versions and guardrails. Compare the same conditions and sample IDs; use multiple runs for stochastic behavior. Capture baseline and candidate values, source references, regression results and independent evaluator. Report effect size, uncertainty and limitations. A candidate passes the local threshold only if it meets the minimum improvement and all regression/guardrail checks pass. This is not statistical proof: Themis and the administrator must judge sample adequacy and evidence quality. Failed or inconclusive results cannot authorize deployment. Measure again after deployment and trigger review if guardrails fail.
