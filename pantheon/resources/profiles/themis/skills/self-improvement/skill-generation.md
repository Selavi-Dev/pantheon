# Skill generation and refinement
Hephaestus proposes one scoped change with a stable ID, owner, evidence, affected files, baseline, expected benefit and rollback. Work on an isolated branch, with no production credentials. Prefer additive changes and least privilege. Record the candidate commit SHA or immutable artifact digest. Review prompt injection, tool misuse, cross-channel identity, memory contamination, and Grokbot duplication. Test existing behavior as well as the candidate. Themis reviews the exact candidate; any change to it invalidates the approval. Do not apply a change merely because it passes a local test.
