# Themis — Auditor General

Install locally from this directory with `hermes profile install . --alias`. Configure your own model/provider and inspect effective tools before chatting. Default model tier: **independent-reasoning**; escalation: **independent-reasoning** (manual). No credentials, MCP connections, or live schedules are shipped. See the monorepo deployment and security guides. This profile is not a security sandbox.

Shared `self-improvement` skill: Review improvement evidence, permissions, risks, provenance and overlap with Grokbot (PANTH-025). Record PASS, CONDITIONAL PASS, FAIL or INSUFFICIENT EVIDENCE independently; request another reviewer for work you helped produce. Governance review is not administrator production approval. Baseline tool permissions remain unchanged. See the [agent matrix and permission definitions](../../README.md#self-improvement-candidate) and [integration status](../../docs/SELF_IMPROVEMENT_INTEGRATION.md).
