# Check authority and ownership before work

## Procedure
Identify scope and owner; check existing routine/work IDs; classify actions as read, draft, or consequential; require specific approval for the latter; report unsupported integration rather than simulating success.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
