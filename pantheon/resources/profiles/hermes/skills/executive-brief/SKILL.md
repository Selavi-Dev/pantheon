# Produce a concise executive brief

## Procedure
Read authorized agenda, commitments, decisions and existing operational reports; rank three priorities; identify blockers and source freshness; include missing inputs; avoid rerunning operational routines.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
