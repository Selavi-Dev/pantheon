# Apollo — Creative Director

Install locally from this directory with `hermes profile install . --alias`. Configure your own model/provider and inspect effective tools before chatting. Default model tier: **creative-multimodal**; escalation: **professional** (manual). No credentials, MCP connections, or live schedules are shipped. See the monorepo deployment and security guides. This profile is not a security sandbox.

Shared `self-improvement` skill: Draft clear improvement reports from verified findings, preserving uncertainty, evidence references and review status (PANTH-026). Mark unverified results as such. Return local drafts only; sending or publishing requires separate explicit authorization. Baseline tool permissions remain unchanged.
