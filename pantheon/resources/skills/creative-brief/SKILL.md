# Generate differentiated creative directions

## Procedure
Define audience, goal, constraints and success criteria; develop at least three distinct concepts; critique each; recommend direction and handoff assets; label mockups.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
