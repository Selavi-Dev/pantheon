# v0.2.0 update — proposed release notes

Added shared self-improvement skill and bounded reflection, root-cause, skill-generation and evaluation playbooks. Added governance policy, eight-agent role mapping, two disabled routine definitions, local review workflow with evidence and candidate binding, Obsidian lesson export, tests and an additive update installer in the separately supplied update ZIP. The integrated source candidate uses the per-profile installer; it does not bundle the old update application script.

The publication candidate now integrates the supplied v0.1.0 source with all eight profile grants, role-specific directives, complete skill support files, consistent 0.2.0 source metadata, and two native disabled routines. The local workflow validates persisted evidence before reuse; note export renders before creating a new file. The planner reserves paused equivalent routines as well as active jobs. Release validation remains effective under optimized Python.

Not included: scheduler activation, release tag, deployment, live connectors, a mounted private Obsidian vault, installed-Hermes acceptance evidence, or an authenticated approval service. Source integration does not establish production readiness. No operational Grokbot routine is modified.
