# Obsidian improvement note template

Suggested private vault path: `Pantheon/Improvement/Inbox/SI-<ID>.md`. A template is not permission to write. Use the local CLI to render a candidate note or create a new file in an explicitly approved directory. Do not overwrite or automatically promote notes.

## Record
- Proposal ID and date
- Classification: observation / hypothesis / candidate evidence / validated lesson / superseded
- Owner and affected workflow
- Evidence references and access classification
- Baseline, candidate, sample size, minimum improvement, guardrail results
- Alternative explanations and limitations
- Exact candidate digest, governance review and decision reference
- Rollback plan and post-deployment observation window
- Post-deployment evidence and confirmed outcome (leave blank until verified)
- Related notes, duplicate findings, and supersession links

Mnemosyne drafts and curates; Argus verifies evidence; Themis reviews classification and access; Hermes routes unresolved questions. Promote to a validated lesson only after independently checking the supporting evidence. Keep secrets, client records and private transcripts out of public source and shared vaults.
