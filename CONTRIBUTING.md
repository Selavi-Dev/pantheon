# Contributing

Open an issue describing the intended behavior, evidence, scope and test plan. Keep changes focused. Changes to shared skills or the constitution must update all bundled copies (run `python scripts/sync_templates.py`), and then pass validation and unit tests. Changes to privileges, approval semantics or data classifications require security review. Do not contribute private agent exports, real customer data or credentials. Use fixtures. Document known limitations. The maintainers decide release readiness; contributions are offered under the repository's MIT license.
