# Audit a claim independently

## Procedure
Define claim and acceptance criteria; inspect underlying evidence, not summaries; record gaps and counterexamples; classify each finding and severity; issue PASS, CONDITIONAL PASS, FAIL or INSUFFICIENT EVIDENCE.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
