# Prepare implementation specification

## Procedure
Define requirements and nonrequirements; specify interfaces, data flows, dependencies and acceptance tests; decompose work packages; hand off to designated implementation owner.

## Output contract
Return evidence, uncertainty, owner and next action. If a required integration is missing, return a proposed artifact and state the blocker. Apply the Pantheon Constitution; never equate this procedure with permission to execute.
